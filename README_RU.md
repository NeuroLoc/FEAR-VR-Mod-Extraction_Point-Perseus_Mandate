# F.E.A.R. VR — Extraction Point, Perseus Mandate и оригинальная кампания

> **Выпуск NeuroLoc:** `v1.1.1`

[English version](README.md)

**Неофициальная VR-модификация для F.E.A.R., F.E.A.R. Extraction Point и F.E.A.R. Perseus Mandate.**

**NeuroLoc** адаптировал **Extraction Point** и **Perseus Mandate** для VR и значительно переработал VR-модификацию оригинальной **F.E.A.R.** В комплект входят только файлы VR-модификации. Оригинальную игру или нужное дополнение требуется установить отдельно.

В рамках проекта выполнены сотни исправлений и доработок: обратный инжиниринг, адаптация интерфейсов движка, исправление ошибок, тестирование и реализация собственных VR-функций.

## Видео геймплея в VR

NeuroLoc записал геймплей в VR из обоих дополнений — **Extraction Point** и **Perseus Mandate**. Комментарии в видео на русском. [Смотреть на YouTube](https://www.youtube.com/watch?v=UFFo9qezZYE)

[![Превью видео с геймплеем Extraction Point и Perseus Mandate в VR](https://i.ytimg.com/vi/UFFo9qezZYE/maxresdefault.jpg)](https://www.youtube.com/watch?v=UFFo9qezZYE)

## Поддерживаемые игры

- **F.E.A.R.**
- **F.E.A.R. Extraction Point**
- **F.E.A.R. Perseus Mandate**

Предусмотрена совместимость с поддерживаемыми выпусками игр из **GOG** и **Steam**. Некоторые особенности зависят от версии игры; см. раздел «Важные замечания о совместимости» ниже.

Проект распространяется в **едином комплекте 3-в-1**, который включает модификации для всех трёх игр. Установщик позволяет выбрать, для каких именно установленных игр применять VR-мод: устанавливать все три необязательно.

## Основные возможности и улучшения

Проект включает сотни изменений, в том числе:

- VR-порты для Extraction Point и Perseus Mandate.
- Катсцены, которые раньше показывались на плоском экране, можно смотреть в стереоскопическом 3D VR. Во время сцены можно свободно поворачивать голову и оглядываться, а камера следует заданному сюжетом маршруту. Переключение между плоским экраном и 3D доступно в игровых настройках VR.
- Исправления совместимости с движком, рендерингом, камерой, полем зрения (FOV), меню и HUD.
- Поддержку оружия, уникального для дополнений, и доработки ручной VR-перезарядки.
- Исправления физического захвата предметов, взаимодействий руками и системы кобур.
- Физический присед и улучшения взаимодействия с предметами у пола.
- Исправления столкновений персонажа с окружением.
- Улучшенное VR-взаимодействие с лестницами в Perseus Mandate.
- Собственную запястную шкалу Slow-Mo.
- Двуязычный VR-интерфейс: русский и английский.
- Раздельные настройки и пользовательские профили для каждой игры.
- Собственные лаунчеры с запуском в VR и обычном режиме.
- Исправления работы с памятью, сохранениями, загрузкой уровней и сюжетными переходами.
- Общий установщик с резервным копированием, обновлением, удалением и проверкой файлов.

Часть функций и исправлений относится только к определённой игре. Это краткое описание, а не полный список изменений: подробности приведены в [`CHANGELOG_RU.md`](CHANGELOG_RU.md).

## Требования и установка

**Понадобятся:**

- Установленная совместимая PC-версия нужной игры.
- VR-шлем и совместимая среда выполнения **OpenXR**.
- Единый установочный комплект VR-модификации (3-в-1).

**Установка:**

1. Скачайте архив комплекта **3-в-1** в разделе **Releases** этого репозитория.
2. Распакуйте архив.
3. Запустите установщик из комплекта.
4. Выберите одну или несколько игр, для которых хотите установить VR-мод.
5. Следуйте указаниям установщика.
6. Для запуска используйте отдельный лаунчер соответствующей игры.

По умолчанию VR открывается в окне 1280×960. Этот параметр можно изменить в настройках лаунчера. В новых профилях обучающие карточки включены.
<!-- readme-review: VR-FIRST-RUN-DEFAULTS-449 -->

Для запуска через Steam Link назначьте SteamVR средой выполнения OpenXR в настройках SteamVR. Затем откройте рабочий стол в Steam Link и запустите VR-лаунчер игры. Для возврата к Virtual Desktop выберите VDXR в настройках Virtual Desktop Streamer.

В новых профилях по умолчанию включён **«Автоподбор»**.

В комплект **не входят оригинальные исполняемые файлы игр**.

## Управление

В раскладке VR можно переназначить меню и фонарь. Удержание Y по умолчанию открывает меню. Этот резерв отключается в настройках раскладки. У фонаря есть отдельный сброс к штатному жесту у лба.

Раскладка учитывает доступные входы OpenXR для каждой руки. Для Trigger и Grip можно назначать нажатие и удержание. Если нужно записать проблему с контроллером, включите «Запись диагностического журнала» в раскладке. Файл VR_Input_Diagnostics.log появится в папке игры. Сенсорные касания по умолчанию выключены. Для их назначения включите «Использовать сенсоры (эксперимент)». Задержку можно задать от 0 до 5 секунд, значение 0 отключает её. Пользователь PICO подтвердил работу VR-ввода и сообщил о частых случайных касаниях до появления этой настройки. Новые настройки NeuroLoc проверил на Meta Quest 3.

## Обновление и удаление мода

### Обновление

Закройте игру и её VR-лаунчер. Скачайте и распакуйте новый комплект 3-в-1 из [Releases](https://github.com/NeuroLoc/FEAR-VR-Mod-Extraction_Point-Perseus_Mandate/releases). Запустите установщик и выберите ту же папку игры. Новую версию NeuroLoc можно установить поверх предыдущей. Установщик сохраняет первоначальные резервные копии для полного удаления.

### Удаление

Закройте игру и её VR-лаунчер. Запустите `УДАЛИТЬ VR-МОД.exe` в папке игры. Деинсталлятор восстанавливает оригинальные файлы игры из резервных копий и сохраняет игровые сохранения и сторонние плагины. Храните журнал установки и папку резервных копий до завершения удаления.

## Важные замечания о совместимости

> [!IMPORTANT]
> NeuroLoc полностью протестировал все три игры в версиях GOG и Steam на своём единственном шлеме **Meta Quest 3**. Другие шлемы NeuroLoc не тестировал. Они могут работать через OpenXR.

- Установщик предусматривает версии игр из Steam и GOG, однако поведение может зависеть от конкретной сборки и состояния установленных файлов.
- Для **Extraction Point** и **Perseus Mandate** предусмотрена автоматическая подготовка исполняемых файлов к работе с увеличенным адресным пространством (**Large Address Aware, LAA**) перед VR-запуском, с сохранением резервной копии при изменении файла.
- **Оригинальная F.E.A.R. в Steam:** в проверенной версии изменение флага LAA приводит к ошибке запуска Steam. Поэтому автоматическое изменение исполняемого файла Steam-версии оригинальной F.E.A.R. не выполняется. Это не означает отсутствия VR-поддержки, но может ограничивать доступное игре адресное пространство. Установщик показывает соответствующее уведомление.
- В проверенной версии **GOG F.E.A.R.** флаг LAA уже присутствует в исходном исполняемом файле.

Если запуск не удаётся, укажите точную версию игры и магазин, из которого она установлена, при создании сообщения об ошибке.
